# ケアマネ支援ソフト（居宅介護支援向け・ブラウザ版）

ブラウザだけで動く、介護支援専門員（ケアマネジャー）向けの業務ソフトです。
インストールやサーバーは不要で、`index.html` をブラウザで開けば使えます。

## 使い方

1. `index.html` を Chrome / Edge などで開く
2. 初回は「デモデータを読み込む」で操作感を確認するか、「設定・マスタ」で事業所情報・地域区分・担当者を登録
3. データはブラウザ内（localStorage）に保存されます。**定期的に右上の「バックアップ」で JSON を保存してください**

テスト（計算ロジック）：`node tests/run.js`

## 機能

- **やること（ダッシュボード）**：認定期限（60日前〜）、短期目標の期間切れ、同意日の未記録、担当者会議の未記録、当月モニタリング未実施（20日以降は赤）、テレビ電話モニタリングの2ヶ月連続、利用票未作成、限度額超過、前月実績の未確定（10日まで）、短期入所が認定期間の半数超過、65歳到達
- **利用者**：かな・カナ・漢字・被保険者番号のインクリメンタル検索（`/` キー）、認定履歴（区分変更・更新申請中を含む）、有効期間の自動計算ボタン（6〜48ヶ月、月途中開始に対応）
- **ケアプラン（第1〜3表）**：認定有効期間から目標期間を自動提案、期間の逆転・認定期間超過・同意日などのリアルタイム整合性チェック、前回プランの複製（期間は新しい認定に合わせて振り直し）、確定（同意・交付）とロック、週間計画のグリッド表示、印刷
- **利用票・提供票（第6・7表）**：カレンダーをクリック／ドラッグで入力、曜日ボタンで一括入力、前月の曜日パターンからコピー、予定→実績への反映、予定と実績の差分表示、実績確定
  - 区分支給限度基準額の管理（月途中の区分変更は重い方の限度額、日ごとの要介護度で単位を算定）
  - 超過分を充当する行の指定、全額自己負担額の計算
  - 地域区分単価（人件費割合 70/55/45%）、処遇改善加算等（限度額対象外）、1〜3割負担の端数処理
- **支援経過（第5表）**：定型文ボタン、Ctrl+Enter で保存、モニタリング実施の同時登録、分類・全文検索、印刷
- **モニタリング**：12ヶ月の実施状況、短期目標ごとの評価、テレビ電話の要件確認
- **サービス担当者会議（第4表）**：出席者・照会内容、保存時に支援経過へ自動記録、印刷
- **給付管理・請求**：取扱件数（要支援は1/3換算）による逓減区分の判定、居宅介護支援費(I)/(II)、運営基準減算、特定事業所集中減算、各種加算と併算定チェック、給付管理票・居宅介護支援費の CSV 出力

## 法令準拠についての重要な注意

- 単位数・単価・限度額は**令和6年度介護報酬改定**をもとにしています（`js/master.js`）。改定・期中改定（処遇改善加算の率など）や保険者独自の取り扱いがあるため、**運用前に必ず公式の「介護給付費単位数等サービスコード表」・告示・解釈通知・Q&Aと照合してください**。マスタ画面で「要確認」と表示される項目は特に確認が必要です。
- 国保連への**伝送**（インタフェース仕様書準拠の CSV／電子請求）、サービスコード（6桁）、公費・高額介護サービス費・食費居住費、介護予防支援・総合事業の請求には対応していません。
- 個人情報をブラウザに保存する仕組みのため、実運用では端末の管理・暗号化・アクセス制御など「医療情報システムの安全管理に関するガイドライン」等に沿った対策が必要です。

```
css/app.css
js/util.js      日付（和暦）・文字列・CSV

js/store.js     データ保存
js/calc.js      計算・チェック・アラート（DOM 非依存）
js/ui.js        画面部品
js/views/*.js   各画面
js/print.js     帳票印刷
js/demo.js      デモデータ
tests/run.js    計算ロジックのテスト
```
